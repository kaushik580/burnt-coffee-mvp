# Burnt Coffee MVP

This is a working dummy prototype for the Burnt Coffee platform.
It includes HTML, CSS, and Vanilla JavaScript with a mock JSON database simulating cross-platform product searches.

## How to Host on GitHub Pages (Free)

1. Create a GitHub Account (if you don't have one) at github.com.
2. Click the '+' icon in the top right and select **New Repository**.
3. Name your repository `burnt-coffee-mvp` and make it Public. Click **Create repository**.
4. On the repository page, click **uploading an existing file**.
5. Extract the files from this ZIP and drag `index.html`, `style.css`, and `app.js` into the browser window. Commit the changes.
6. Go to the **Settings** tab of your repository.
7. Click on **Pages** in the left sidebar.
8. Under "Build and deployment", set the Source to **Deploy from a branch**.
9. Under "Branch", select `main` (or `master`) and click **Save**.
10. Wait 1-2 minutes, refresh the page, and GitHub will provide a live URL (e.g., `https://yourusername.github.io/burnt-coffee-mvp/`) where your prototype is hosted!
